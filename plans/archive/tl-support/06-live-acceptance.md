# 06 — Test na żywym intranecie

## Goal
Potwierdzić, że wtyczka na prawdziwym intranecie i prawdziwym zespole daje poprawne dane i jest użyteczna w codziennej pracy.

## Scope
In:
- Instalacja `dist/` jako unpacked w Chrome
- Odświeżenie bieżącego i poprzedniego miesiąca
- Porównanie wyrywkowe z intranetem: 3 osoby × godziny kilku dni, urlopy, sumy
- Zapis uwag i błędów (bez danych osobowych) do `plans/tl-support/06-feedback.md` lub nowego etapu

Out:
- Nowe funkcje (→ nowy etap / backlog)

## Acceptance criteria
- [x] Wtyczka wykrywa intranet, przycisk i panel działają
- [x] Odświeżenie przechodzi dla całego zespołu bez błędów (lub błędy opisane)
- [x] Wyrywkowa zgodność godzin, urlopów i sum z intranetem (potwierdzenie użytkownika)
- [x] Święta i weekendy poprawnie oznaczone
- [x] Czas odświeżenia miesiąca akceptowalny dla użytkownika
- [x] Decyzja użytkownika: MVP gotowe / lista poprawek

## Verification
Jawne potwierdzenie użytkownika każdego kryterium.
